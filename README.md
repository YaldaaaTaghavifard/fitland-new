## ۱. معرفی و انگیزه پروژه (Overview)
«فیت‌لند» یک پلتفرم دوطرفه ورزشی و سلامت محور است که با الگوبرداری از برترین استانداردهای محصولی (مانند salamatyareman و yazd-ec-project) برای اتصال مستقیم ورزشکاران، مربیان خبره و باشگاه‌ها طراحی شده است. فیت‌لند بر حل چهار اصطکاک بنیادی تمرکز دارد:
1. **تسهیل مالی با پرداخت اقساطی دمو:** امکان عضویت با تنها ۳۰٪ پیش‌پرداخت و ۲ الی ۶ قسط بدون کارمزد.
2. **رزرو هوشمند با پیشگیری از تداخل (Collision Avoidance):** عدم امکان رزرو همپوشان در یک ساعت.
3. **دو زبانه واقعی متمرکز (فارسی و انگلیسی):** پشتیبانی کامل از RTL (فونت Vazirmatn) و LTR (فونت Inter).
4. **پرونده علمی کسب‌وکار (`/business-case`):** بوم تعاملی ۹ بخشی، ماشین‌حساب اقتصاد واحد و آزمونگر ۱۲ سناریوی عملیاتی.

## ۳. راهنمای نصب و اجرا روی سیستم‌عامل مک (macOS M1 / Apple Silicon)

این پروژه با معماری ARM64 و پردازنده‌های سری M اپل سازگاری ۱۰۰٪ دارد.

### پیش‌نیازها:
- نصب **Node.js** (نسخه ۱۸ یا بالاتر — پیشنهاد: Node.js 20 LTS)
- ابزار **npm**

### مراحل اجرا در ترمینال macOS:
```bash
# ۱. وارد پوشه پروژه شوید:
cd fitland-project

# ۲. پکیج‌های پروژه را نصب کنید:
npm install

# ۳. سرور توسعه محلی را اجرا نمایید:
npm run dev
```

سامانه بر روی آدرس محلی `http://localhost:3000` (یا پورت پیشنهادی ترمینال) در دسترس خواهد بود.

## ۵. قابلیت‌های متمایز و نوآوری‌ها

1. **موتور رزرو بدون تداخل زمانی:** ممانعت خودکار از ثبت دو کلاس در یک بازه زمانی مشترک برای یک ورزشکار.
2. **درگاه تقسیط و صدور فاکتور قابل چاپ:** محاسبه خودکار سررسیدها با تاریخ هجری شمسی و میلادی، پیش‌پرداخت انعطاف‌پذیر و مانده بدهی.
3. **بوم مدل کسب‌وکار زنده (Interactive BMC):** قابلیت افزودن یا حذف فرضیات در هر یک از بلوک‌های ۹گانه با ماندگاری در LocalStorage.
4. **شبیه‌ساز اقتصاد واحد استارتاپی:** محاسبه آنی شاخص‌های ARPU، LTV، CAC و نسبت LTV/CAC به همراه پیش‌بینی گردش مالی سالانه (ARR).
5. **پایشگر سناریو (Scenario Runner Modal):** ابزار ویژه هیئت داوران برای اجرای زنده ۱۲ آزمون خودکار با گزارش خط‌به‌خط.
