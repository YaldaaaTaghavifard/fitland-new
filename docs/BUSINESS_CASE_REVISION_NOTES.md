# گزارش اصلاحات پرونده تحلیلی کسب‌وکار

تاریخ اصلاح: ۱۰ نوامبر ۲۰۲۶

## فایل‌های تغییر یافته
- `src/pages/public/BusinessCasePage.jsx`
- `src/services/dataService.js`
- `src/services/scenarioService.js`
- `docs/BUSINESS_MODEL.md`

## اصلاحات انجام‌شده
- جایگزینی هشت پرسش قبلی با عین هشت محور ارزیابی ایده بالغ مندرج در صورت‌پروژه درس.
- تفکیک فرضیه از شواهد و حذف آمار تأییدنشده از متن پرونده.
- افزودن بیانیه ارزش پیشنهادی، ارزش کاربردی و مبادله‌ای و چهار کارکرد واسطه‌گری.
- بازنویسی محتوای پیش‌فرض BMC با اولویت مدل درآمدی B2B2C و حذف درصدهای قراردادی بدون پشتوانه.
- بازنویسی تحلیل رقبا بر اساس صفحات رسمی جیموا، دمبل و Trainior؛ با ذکر محدودیت بررسی.
- بازنویسی پرسوناها به‌صورت فرضی و افزودن مدیر باشگاه به‌عنوان مشتری اصلی B2B.
- اصلاح محتوای AIDA و حذف وعده‌های اجرانشده مانند ضمانت بازگشت وجه و پرداخت واقعی.
- افزودن جدول کانال، اقدام و شاخص سنجش قیف.
- اصلاح ماشین‌حساب برای نمایش LTV درآمدی و LTV سود ناخالص، افزودن حاشیه سود ناخالص و شفاف‌سازی فرضیات.
- همسان‌سازی سناریوی SCN-12 با مقادیر پیش‌فرض ماشین‌حساب.
- افزودن عملیات بازنشانی BMC به الگوی اصلاح‌شده؛ داده‌های سفارشی قبلی بدون اقدام کاربر پاک نمی‌شوند.

## آزمون‌ها و محدودیت
- `node --check` برای `dataService.js` و `scenarioService.js` موفق بود.
- بررسی نحوی JSX/JavaScript با TypeScript compiler و تنظیم JSX انجام شد و خطای نحوی گزارش نشد.
- اجرای `npm run build` انجام نشد؛ وابستگی Vite در محیط حاضر نصب نبود و نصب npm به علت عدم دسترسی/پاسخ شبکه کامل نشد. پیش از تحویل نهایی، روی سیستم توسعه با `npm install` و سپس `npm run build` و `npm run lint` آزمون کامل اجرا شود.

## اقدام دستی پس از جایگزینی فایل
اگر قبلاً BMC را در مرورگر ویرایش و ذخیره کرده‌ای، داده قبلی در LocalStorage حفظ می‌شود. برای بارگذاری محتوای پیش‌فرض اصلاح‌شده، وارد تب BMC شو و دکمه «بازنشانی بوم اولیه» را بزن؛ این عمل فقط BMC ذخیره‌شده را جایگزین می‌کند.
